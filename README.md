# ICS-Digital-Twin-IDS

# ICS Digital Twin Intrusion Detection System

## Project Overview
A machine learning project for intrusion detection
in Industrial Control Systems (ICS), with a
Streamlit dashboard for model evaluation.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

## Features
- Machine learning model evaluation
- Classification report
- Performance metrics visualization
- Interactive Streamlit dashboard

## How to Run
1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the dashboard:

   streamlit run app.py
